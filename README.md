# Kozak Lab — one-page website

Static, Polish-language portfolio page for dental technician Mikołaj Kozak.

## Preview locally

From this directory, run `python3 -m http.server 4173`, then open `http://localhost:4173/`.

The page uses only local HTML, CSS, and images. Contact buttons open the public [@kozak_lab Instagram profile](https://www.instagram.com/kozak_lab/). The two photographs are generated illustrations and are labelled as such on the page.

The design and content plan is in [PLAN.md](PLAN.md). Confirm the product list, practical ordering details, contact preferences, and approved work photographs before publishing.
