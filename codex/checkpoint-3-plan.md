# Checkpoint 3 plan — journal MVP

## Goal

Show how Kozak Lab can publish work history and useful articles while keeping the current site static. Give visitors a readable, linkable article and Mikołaj a simple file-based pattern for future entries.

## Scope

1. Add a “Z pracowni” section to the home page, with a featured article and clear navigation.
2. Create one standalone article page using the same visual language, a descriptive title, summary, internal links, and a source link to the relevant Instagram work.
3. Label this first article as an editorial draft awaiting Mikołaj's review; avoid invented case details, clinical recommendations, and claims of his authorship or use of specific new technologies.
4. Document how to add another static article now and which content fields could map to a future CMS.
5. Verify responsive layout, article links, keyboard navigation, local HTTP, and the absence of broken references. Request independent review before push.

## Editorial sample

The first article will discuss how to document a ceramic restoration in a way that helps a dentist assess form, colour, material, and context. The public Instagram post supplies the example image and material label. All broader copy is a draft to be reviewed and personalized by Mikołaj.
